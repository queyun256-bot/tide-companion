# 潮汐 0.9.1

Windows / macOS 桌面宠物软件：戴跨性别旗帜围巾的小鲨鱼「鲨鲨」、本机用药提醒与 HRT 记录。透明悬浮桌宠、独立管理窗口、托盘或菜单栏入口和系统通知，无需浏览器、网站服务器或云端账号。

0.9.1 修复 Windows 非整数缩放下连续拖动后只能向左上移动的问题。移动窗口时保持固定逻辑尺寸，避免透明窗口逐次变大；托盘归位和显示器变化时的定位使用同一规则。

## 直接使用

**Windows 安装包下载：** [潮汐 v0.9.1 Release](https://github.com/queyun256-bot/tide-companion/releases/tag/v0.9.1)。下载附件中的 `.exe`，同页提供 SHA-256 校验文件。本次公开 Release 仅提供 Windows x64 安装包；它从 `v0.9.1` 公开源码重新构建，不包含已停用的专有 Live2D Core，因此校验值与早期本机安装包不同。

**macOS 版：** 提供 Apple 芯片（arm64）与 Intel（x64）两个 `.app` 压缩包。macOS 13 Ventura 或更新系统，解压后把「潮汐.app」拖入「应用程序」。Mac 菜单、通知提示、首次点击与本机目录已适配；HRT 记录、校准、日历、五款鲨鱼、共享等级和星星使用相同代码。此版使用本地 ad-hoc 签名，未经过 Apple 开发者签名和公证，首次打开方式、功能差异和验证范围见 [macOS 使用说明](docs/macOS.md)。Windows 安装包保持原文件不变。

**安装版：** 双击 `dist/installers/潮汐-Setup-0.9.1-x64.exe`，按照简体中文向导选择安装目录。安装包包含全部运行文件，无需联网下载运行时；为当前 Windows 用户安装，创建桌面和开始菜单快捷方式，并提供系统卸载入口。安装前从托盘退出正在运行的旧版。安装版继续读取原本机记录与皮肤；卸载保留这些数据。应用和安装包显示名统一为「潮汐」，不包含公司信息；安装包目前未配置代码签名。

**便携版：** 双击 `dist/Tide-Companion-win32-x64/Tide-Companion.exe`。这是包含运行时的 Windows x64 便携文件夹，请保留整个目录，不能只复制 exe。首次运行会创建「潮汐」开始菜单快捷方式，用于 Windows 通知。

首次使用会引导选择 **MTF / FTM** 并确认药代模型的 **体重（kg）**，完成后保存到本机。已有资料会预填原模式和体重，供确认；不会重置历史记录。后续打开软件沿用上次保存的模式与配色，模式和体重仍可在界面及模型设置中修改。尚未完成引导时，即使从后台启动也会显示手账。需要再次确认时，可在「桌宠与设置 → 初始设置：模式与体重」重新打开；取消不会改动已保存的数据。重装会保留原数据，已完成引导的档案不会每次重复弹出。

- 左上角 **MTF / FTM** 切换粉色 / 蓝色主题及默认参考背景；自定义参考背景和个人校准基线会保留。
- 长按鲨鱼头顶鱼鳍，进入提起姿态后拖动；松开会柔和落回原姿态。双击鲨鱼打开面板。左下角手账按钮点一下打开，再点一下收起；若手账已最小化则先恢复。摸摸、轻蹭、打盹可互动；星星按钮查看余额。
- 原创圆滚鲨鱼会原地歪头、摇鳍、摆尾、伸懒腰和轻蹭。心情记录会改变动作频率、选择与台词，不推测健康状态。闲置后渐渐打盹，再随机自然醒来；摸摸可以唤醒。
- 长按身体可轻蹭，按住滑动可抚摸；按时确认既定用药会慢慢攒下星星。底部图标闲置后隐藏，鼠标移动可唤出；不会擅自移动桌宠窗口。详见[行为说明](docs/pet-behavior.md)。
- 默认在前台游戏、视频、无边框全屏窗口出现时隐藏桌宠，结束全屏后恢复。设置可以关闭此功能。
- 在「桌宠与设置」修改名字，概览、桌宠、托盘和提醒随之同步；默认名为「鲨鲨」。
- 换肤页保留五种内置鲨鱼。Live2D 入口和渲染暂时隐藏；已导入文件、原选择与缩放继续保留，原来使用模型时暂以浅海蓝鲨鱼陪伴。
- 关闭管理面板后继续留在系统托盘；右键托盘选择退出，才会停止提醒。

## 日历与每日心情

- 「日历」按本机日期查看当天所有实际用药和化验，显示药物、给药方式、用量、时间及检测结果，不因 MTF / FTM 模式隐藏历史。支持切换月份、回到今天和从所选日期补录用药/化验；提醒计划不会当作实际用药。
- 今天的心情可在概览或日历选择，每天只能保存一次，关闭重开也不能修改。不选择时默认「平平淡淡」；默认值与明确选择分别标注。历史心情只读，新的一天恢复默认，仍可选择当天心情。
- 心情会改变鲨鲨当天的动作频率、动作选择与台词。每日心情独立长期保存，并随健康备份导出。明确导入备份会恢复历史心情，但保留本机今天已经确认的选择。
- 更新时按旧互动日志中每天最早的一次明确选择迁移；普通互动不生成心情，日志轮转不再丢失每日记录。旧版本已经清除的历史无法补回，未留存的日期显示默认。

## 记录与双激素曲线

1. 先选择「给药方式」，再选「使用药物」。例如「舌下含服 → 戊酸雌二醇 EV」，下方小字显示「补佳乐 Progynova」等代表药品；收起和展开列表中的每个给药选项都显示透明细线图标，随粉色 / 蓝色主题改变；下拉支持方向键、Home/End、Enter/空格、Esc 与 Tab。目录包含10类方式、40种药物组合，涵盖E2/T常见制剂、CPA、螺内酯、比卡鲁胺、5α还原酶抑制剂、孕激素与GnRH类。目录用于记录既有方案，不表示各条目获准用于GAHT或被推荐使用。
2. 到点提交 Windows 通知并显示桌宠气泡。提醒本身不会产生实际使用记录。
3. 使用后点「记录使用」，核对用量和实际时刻；可补录历史、编辑或删除错误记录。
4. **MTF显示粉色E2（pg/mL）＋紫色CPA（ng/mL），不显示T曲线。FTM默认显示蓝色总T（ng/dL），可勾选展开粉色E2。** 无需选择单一给药方式来查看总贡献。
5. 按住鼠标右键拖动标线，查看该时刻的估计。键盘方向键移动15分钟，Shift加方向键移动1小时。标线保留所选时间，拖动不会被提醒刷新打断。
6. 「化验与校准」填写采血时间、结果及单位；E2、T与CPA分别拟合，实测点保留在图上。切换模式保留全部历史数据。

用药、提醒、化验、模型、改名和初始设置等弹窗只通过界面按钮或 Esc 关闭，点击背景不会丢失草稿；给药列表展开时，第一次 Esc 收起列表，再按一次关闭弹窗。

页面切换、弹窗与按钮有轻量过渡。打开浓度曲线页时，曲线从左向右展开，坐标轴与化验点保持稳定；开始操作标线会立即结束入场动画。保存、定时更新和后台消息不会重复播放转场。「减少动画」和系统减少动态效果偏好会关闭这些动画。

## 日期与时间选择

记录用药、提醒和化验使用与粉/蓝主题一致的日期弹层，日历月份也使用自绘月份网格。可选日期、填写小时和分钟，再点「确定」；也能直接输入精确日期和时间。Esc 先收起选择器，再关闭父表单；选择器外侧点击不会丢掉整个表单。保留本机时间语义，非法日期或不存在的夏令时时刻会提示，不自动改成其他日期。

## 界面与陪伴

v0.5 使用更柔和的粉色 / 蓝色界面，统一侧栏、卡片、表单和列表的间距与层次；文案改为简短的日常表达。鲨鲨不再每次小动作都说话，连续抚摸时也会安静回应。v0.5.1 进一步减少机械确认和刻意安慰，以眯眼、轻轻靠近和短句回应；连续触摸不会反复重启动作，不同动作自然接续。对话气泡改为圆角卡片，带小尾巴与渐隐过渡，用药提醒有单独的视觉提示。

v0.7 增加五种内置鲨鱼：浅海蓝（随和好奇）、绒绒粉（温柔亲近）、薄荷绿（沉稳慢悠悠）、蜜桃橙（活泼机灵）、暮云紫（安静爱做梦）。「桌宠与设置 → 桌宠换肤」展示配色预览及性格，换肤会同时改变动作节奏、动作偏好和互动台词，保留自定义名字。低落心情下，各种性格都会放轻动作与语气。

概览和设置页里的鲨鱼回放桌宠的实际姿态与动画进度，切换页面不会重新随机一套动作。眨眼、抚摸、睡醒、鱼鳍拖动以及吃星、产星姿态同步。Live2D 入口与渲染暂时隐藏，原模型文件和保存的选择保留；此前使用 Live2D 时，本次统一显示内置浅海蓝鲨鱼。

内置鲨鱼增加不规则眨眼、轻微的视线跟随、点头与错开的鳍尾动作，并随机选择招鳍、拢围巾、侧摇、探头、收尾舒展和轻浮沉等动作，避免连续重复。各性格保持各自偏好，触摸、睡眠和拖动优先。所有动作仍在原窗口内进行；闲置短盹、自然醒来、心情节奏与全屏自动隐藏继续保留。

提醒每30秒检查一次，并在睡眠恢复后检查。完全退出、关机或睡眠期间不能实时提醒；重启或恢复后只汇总各计划最近一次到期事项。Windows 勿扰模式和通知权限可能阻止系统横幅。

## 星星口袋

星星余额、收支明细和成长长期保存在本机，并随健康数据备份导出。设置页可把一颗星星拖到旁边或桌面的鲨鱼身上，消耗 1 颗星星、增加 1 点经验；没有手动加星或购买入口。旧版手动喂出的临时星灯不会换算成余额。

- 正常提醒后，在原定时刻起 2 小时内确认实际使用；实际使用时间也需在这个窗口内，并与提醒时的药物、用量和时长一致。软件按已发出的提醒自动匹配，未提醒的历史补录、测试提醒不奖励。
- 普通用药每次 1 颗，按本机确认日期每天最多 2 颗。计划间隔至少 48 小时的长间隔用药，按每满一天 1 颗计算，单次最多 7 颗；不占普通用药的每日额度。这个规则用于星星奖励，不决定给药频率或用量。
- 每次提醒及同一次实际使用最多奖励一次；编辑、重复保存、删除后重建都不会再次加星。漏记不扣星、不清空余额；删除原用药记录也不扣除已经获得的星星。
- 越多星星会逐级出现更丰富、更明亮的星点、光晕和星环，桌宠与手账共享相同余额和动画进度。减少动画时保留静态星光。
- 五种鲨鱼共享等级与经验，从 1 级到 10 级依次需要 5、8、12、18、26、36、48、62、80 点经验，总计 295 点。满级仍可以投喂，经验保持满格；换肤不会重置成长。
- 2 级后，桌宠在清醒、可见且一段时间没有被互动时，偶尔会从围巾和小鳍旁留下一些星星。所有外观共用本机自然日每天最多一次；2 级为 1–3 颗，之后上限为等级加 1、最多 10 颗，数量越多越少见（相邻数量的概率权重减半）。没有离线补发，也不影响用药提醒奖励额度。
- 吃星会接住小星星、闭眼轻轻咀嚼，再恢复待机；产星使用小鳍托起、星光散开的不同动作。手账与桌宠同步，减少动画时保留静态反馈。一起安静待着也很好，喂食不是每日任务。

## 指南监测参考

浓度曲线页的当前值下方增加指南参考：MTF E2 为 100–200 pg/mL；FTM T 的 400–700 ng/dL 明确限于庚酸/环戊丙酸针剂间隔中点采血，FTM E2 不套用女性化范围，CPA 不设虚构目标。详情列出 Endocrine Society、WPATH SOC8 和 E2 证据综述，解释采血时点及适用条件。它们不参与模型计算，也不把瞬时估计判为“达标”。详见 [参考范围与来源](docs/GAHT-reference.md)。

## 数值范围与限制

16种组合具备参考模型：E2与EV口服、E2与EV舌下、E2凝胶/贴片、EB/EV/EC/EEn肌注、TC/TE/TU肌注、T凝胶/贴片，以及CPA口服。E2/T使用按给药途径区分的多过程数值模型；模型参数是经验模拟假设，不是临床验证结论。旧版EV舌下“仅记录”限制已解除，已有记录和化验自动参与重算，无需重录。

- 尚未化验时，受支持模型显示「未校准参考」。E2/T背景沿用Vlot等2019年成人队列的GAHT前中位数：MTF情境E2约28.6pg/mL、T约548.0ng/dL；FTM情境E2约50.9pg/mL、T约37.5ng/dL。不是治疗目标或治疗后水平；来源及原单位IQR可在模型设置查看。
- 模型设置增加体重（默认70kg，仅为参考假设）和舌下黏膜分流份额（默认11%，经验参数）。EV含服分为黏膜吸收/酯水解与吞咽首过两部分，按片剂标示的EV酯mg记录，活性分子量比例只换算一次。份额不能从含服分钟数准确推定。
- 新E2/T模型不再使用v0.3的教学半衰期和峰值锚定，参考数字可能变化。旧自定义半衰期保留在备份与模型配置中，但不套用到新模型；CPA仍可编辑原一室参数。新参数可在界面查看。
- 同一激素的多个受支持途径先合成，再拟合一个共同倍率，背景只加一次。校准基线与未校准参考背景独立，避免多途径重复计算。
- CPA自身浓度使用Androcur标签约束的一室口服近似，基线0。关键锚点是**100mg（两片50mg）约3h达285ng/mL**，终末半衰期43.9h；吸收常数由峰时推导，生物利用度不重复相乘。其他剂量与重复使用的线性外推未获个体或临床验证。
- **CPA/E2对T的抑制、T芳香化及内源反馈未建模。** CPA曲线不代表T抑制程度或疗效。FTM的可选E2曲线也不能从睾酮用量推算卵巢抑制；没有E2给药时只显示背景情境及带日期的最近实测。
- 颊黏膜、皮下注射、喷雾、植入剂、混合酯、口服TU等尚无独立参数的组合仍仅记录；不会擅自照套肌注或其他途径模型。此类E2/T记录造成未知贡献时，会明确说明无法估计总值的原因。
- 浓度每分钟更新。桌面只将截至当前已发生的给药纳入计算，未来虚线假设不追加给药；提醒计划不自动作为实际给药。导入的未来给药保留并标注“未发生”，到达记录时间后才纳入。添加刚刚发生的口服记录不会瞬时产生峰值。
- 凝胶填写有效成分mg，注射和EV片剂填写对应酯mg；E2贴片填写标称μg/day，T贴片填写标称mg/day，二者不能混用。提前移除贴片后编辑实际佩戴时长。
- 个人校准只拟合幅度。一次测定无法验证峰谷和未来曲线；模型不是实时检测，未经临床验证，不能据此自行调整处方。

[当前模型与数值审计](docs/MODELS-v4.md) · [CPA及论文背景来源](docs/MODELS-v3.md)。第三方许可保存在 `assets/vendor/`。公式与软件测试通过不代表临床准确性已经验证。软件没有剂量推荐、自动补服或治疗目标判断。

## 在 VS Code 开发

打开本目录，安装依赖后按 F5 启动真实 Electron 桌面程序。

```powershell
npm install
npm start
npm test
npm run smoke
npm run pack
npm run installer
```

已固定 `pnpm-lock.yaml`。可用 `pnpm install --frozen-lockfile`；如包管理器未运行 Electron 安装脚本，执行 `node node_modules/electron/install.js`。中国网络可临时指定 npm 镜像及 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。

Git 仓库不包含专有的 `assets/vendor/live2dcubismcore.min.js`，也不包含 `tests/fixtures/` 下的 Haru 样例素材。**0.9.1 已关闭 Live2D，克隆仓库并安装依赖后即可使用五款内置鲨鱼，无需 Core 或样例模型；常规 `npm test` 也不依赖它们。** Live2D 专项测试 `node tests/live2d-renderer-smoke.mjs` 需要先从官方取得有权使用的 Haru 素材，保留许可与引用目录结构，放入 `tests/fixtures/Haru/`。只有研究或恢复 Live2D 渲染时才需另行取得 Core 并确认适用授权。详情见 [本地运行时与许可说明](docs/LIVE2D-runtime.md)。忽略规则仅排除上传，不删除开发机已有文件。

安装包采用 [electron-builder NSIS](https://www.electron.build/v26/docs/nsis/) 向导，配置在 `electron-builder.json`；`scripts/installer.mjs` 在 `dist/installer-stage` 创建独立便携副本，再生成单文件离线安装包及 SHA-256 校验文件到 `dist/installers`。构建需要下载编译工具，最终用户安装不需要。应用 ID 保持稳定以支持覆盖升级；窗口与「潮汐」快捷方式明确绑定同一份外置鲨鱼图标，图标文件名随内容变化，减少旧缓存干扰。登录启动已启用时，安装版首次运行会将启动路径更新为当前程序；卸载只移除指向该安装目录的启动项。

`node tests/calendar-smoke.mjs` 验证日历、全部日记录、默认心情与跨重启日锁。`node tests/onboarding-startup-v060.mjs` 验证后台初次启动、重复进程启动及设置重开引导；可用 `TIDE_TEST_APP_ROOT` 指向实际安装包 ASAR 重测。

`npm test` 覆盖药代数学、叠加和校准、提醒、迁移、存储及模型导入安全。`npm run smoke` 使用独立临时数据目录验证真实桌面双窗口、表单、双曲线、标线、配色、改名、IPC与落盘。`node tests/ui-motion-v5.mjs` 与 `node tests/pet-polish-v5.mjs` 检查真实桌面中的转场、减少动画、气泡及桌宠动作；Live2D及全屏检测另有专项集成测试。`node tests/dialog-picker-v052.mjs` 检查展开选项图标、键盘选择及弹窗草稿防误关闭；`node tests/onboarding-smoke.mjs` 检查首次引导、模式重启恢复和旧资料保留；`node tests/pet-toggle-v051.mjs` 检查手账显隐与提醒入口；安装包生成后运行 `node tests/installer-smoke.mjs --onboarding` 核对解压内容、源文件一致性，并对安装包实际代码再运行引导验证。这些功能测试不是临床验证。

```text
electron/              桌面主进程、托盘、安全桥接、皮肤导入、全屏检测
src/app.js             管理窗口
src/chart.js           双激素图表与鼠标标线
src/hormones.js        双激素参考与校准模型
src/pk.js              模型目录、化验单位与单途径兼容接口
src/pk-mahiro.js       开源参考参数及稳定的双室/三室数值核
src/pet.js             原创鲨鱼互动
src/live2d.js          本地 Live2D 渲染
src/calendar.js        日历与每天的用药、化验、心情
src/journal.js         本地日期归档与月份计算
electron/daily-moods.cjs 每日心情校验、迁移及不可重复选择
assets/                原创 SVG、图标和本地运行库/许可证
tests/                 数值、存储、导入安全及真实桌面测试
docs/                  模型与使用说明
dist/                  Windows 安装包与 macOS 应用压缩包
```

健康记录继续保存在 `%APPDATA%\小浪桌宠\state.json`，沿用旧目录以保留记录。每次写入保存上一版 `state.backup.json`；数据迁移和导入另存恢复快照。文件为本机明文 JSON；皮肤保存在独立的 `skins` 目录，不包含于健康备份。导入只复制模型所引用的资产，不改动原文件。

macOS 首版数据位于 `~/Library/Application Support/潮汐/`。可在 Windows 导出 JSON 备份，再在 Mac 导入；记录、校准、星星账本与经验可迁移，系统登录启动等设备设置不会直接照搬，没有自动云同步。

程序无遥测、云同步或内置联网请求；仅在用户点击来源链接时使用系统浏览器。移除便携程序前请先导出需要的记录，并关闭开机启动。删除软件目录和开始菜单快捷方式后，个人数据目录仍保留。
