# 潮汐

版本 0.9.3

一只戴着跨性别旗帜围巾的小鲨鱼，陪你记录日常，也在桌面上安静待着。

- **桌宠陪伴**：摸摸、轻蹭、打盹、喂星星；可以给鲨鲨起名字，按住鱼鳍移动它。
- **五种外观**：不同配色与性格，各有小动作和台词；桌宠与手账中的鲨鱼同步，成长不会因换肤重置。
- **日历与心情**：查看每天的用药和化验记录，留下一次当天的心情，让鲨鲨以不同节奏陪伴。
- **用药提醒与记录**：设置固定间隔提醒，记录实际使用的药物、剂量与时间，也可以补记、编辑或导出。
- **浓度参考与校准**：查看雌二醇、睾酮和 CPA 的参考曲线，录入化验结果进行个人校准，并拖动标线查看对应时间。
- **星星与成长**：按已有计划记录实际用药，慢慢积攒星星；拖给鲨鲨投喂、增加经验，解锁成长中的小惊喜。
- **个人手账**：MTF 粉色与 FTM 蓝色主题可切换。数据保存在本机，无需账号，支持备份与恢复。
- **多语言**：默认跟随系统，支持英语、简体中文、繁體中文、日本語、한국어和西班牙语；可在设置切换，重启后保留。
- **桌面软件**：提供 Windows 与 macOS 版本；关闭手账后仍可继续陪伴和提醒，完全退出后停止运行。

血药浓度由模型估算，仅供参考，并非实时检测结果。
