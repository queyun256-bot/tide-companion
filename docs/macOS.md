# 潮汐 0.9.2 · macOS

## 选择与安装

- Apple 芯片（M1、M2、M3、M4 等）：选择 `潮汐-0.9.2-macOS-arm64.zip`。
- Intel Mac：选择 `潮汐-0.9.2-macOS-x64.zip`。
- 需要 macOS 13 Ventura 或更新系统，与本项目使用的 Electron 44.7.0 一致。[Electron 44 官方说明](https://www.electronjs.org/blog/electron-44-0#removed-macos-12-support)

在 Mac 上用系统“归档实用工具”解压，把“潮汐.app”拖入“应用程序”文件夹，然后双击打开。运行时已经包含在应用中，不需要安装 Node.js 或 VS Code。升级前从菜单栏退出潮汐，再替换应用。

此版本使用本地 ad-hoc 代码签名，没有 Apple Developer ID 签名和公证。若首次打开提示开发者无法验证，确认使用的是本次提供的原始压缩包后，可在“系统设置 → 隐私与安全性”中选择“仍要打开”，再确认打开。这是对单个应用的确认，不需要关闭系统整体安全检查。若系统提示文件被损坏或含恶意内容，请保留错误信息，不要把它当作普通首次确认。[Apple 打开未公证应用的说明](https://support.apple.com/en-us/102445)

## 使用

首次打开填写 MTF / FTM 和模型体重。用药、化验、浓度估算、提醒、日历心情、五款鲨鱼、共享等级、星星账本、喂食和 0.9.1 固定尺寸拖动逻辑与 Windows 版共用。长按鱼鳍约半秒后拖动，松手放下；触控板需要持续保持左键按下。

0.9.2 的用药星星按已有提醒计划匹配：实际使用时刻在预定时刻前后 2 小时内（含边界），药物、用量及使用时长一致，即可得星，无需先弹出通知。允许晚些新增补记，原已存记录和编辑不会追发；同一次预定用药及同一次实际使用最多奖励一次。普通奖励每次 1 颗，按本机发星日期每天最多 2 颗；间隔至少 48 小时的计划按完整天数计算，单次最多 7 颗，不占普通额度。未来用药不奖励，漏记不扣星。

菜单栏的小鲨鱼可以打开手账、隐藏桌宠或退出。点击 Dock 图标可重新打开手账；关闭手账窗口仍保留桌宠和提醒，`⌘Q` 完全退出。应用菜单提供编辑与窗口操作，支持复制、粘贴等标准快捷键。通知还受 macOS 的通知授权与专注模式影响。

本次 macOS 版本的明确差异：

- 暂不自动检测其他应用的全屏状态，需要时从菜单栏隐藏桌宠。界面不显示无效的自动隐藏开关。
- 登录时启动请在“系统设置 → 通用 → 登录项”中添加潮汐。此版本不在应用内自动注册登录项。已完成引导的登录启动可隐藏手账；新资料仍显示引导。
- Live2D 同 Windows 0.9.2 暂时隐藏，保留五款内置鲨鱼。

应用没有新增录屏或辅助功能权限需求。

## 本机数据与迁移

数据目录为 `~/Library/Application Support/潮汐/`；健康记录、每日心情、星星收支及成长保存到 `state.json`，写入备份与恢复快照规则沿用 Windows 版。删除或替换 `.app` 不会删除这些本机记录。

从 Windows 迁移时，在“桌宠与设置 → 导出备份”生成 JSON，在 Mac 同一页面导入。五种鲨鱼仍共用等级、经验和每天一次产星机会。系统通知、登录启动及其他设备偏好保留目标电脑当前设置。两台电脑是独立本机档案，没有自动同步；Live2D 文件不包含在健康备份内。

## 构建与验证边界

开发者在项目目录运行 `npm run pack:mac` 构建两个架构。构建工具下载并校验相应的 Electron Darwin 运行时，生成应用包、macOS 图标、签名及 SHA-256 校验文件。0.9.2 应用包不包含专有 Live2D Core，并包含与源码一致的根 `LICENSE`；开发机自行取得的 Core 原文件保留。应用 ZIP 必须保留 UNIX 可执行权限与 framework 符号链接，不能把它作为普通 Windows 文件夹重新压缩。

本次构建环境为 Windows。已增加 Mac 平台分支、菜单、数据路径、首次引导和能力显示的自动测试；包结构、源码一致性与代码签名可以离线核验。尚未在 Mac 实机运行验证通知授权、Dock/菜单栏显示、真实触控板拖动、原生拖放投喂和睡眠恢复；这些不能用 Windows 测试替代。

Mac 实机验收时，应验证首次引导、重启后的模式与数据、长按鱼鳍四方向拖动及桌面点击、手账开合、一次真实通知、一次拖星投喂与重启余额，并核对不同显示缩放和多显示器的位置。所有功能验证应使用独立测试资料。
