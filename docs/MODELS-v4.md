# 血药浓度引擎 v4：EV 舌下与多过程参考模型

核查日期：2026-10-12。本文件取代 v3 中“EV 舌下仅记录”和旧 E2/T 教学曲线的当前行为说明；v1–v3 保留作为历史记录。当前实现分布在 `src/pk-mahiro.js`、`src/pk.js`、`src/hormones.js`。输出是根据记录重新计算的参考模拟或实测幅度校准曲线，不是血液实时检测。

## 这次修复了什么

上一版把 `e2-ev-sublingual` 归为 `record-only`，引擎在读到这一记录后直接返回 E2 `null`，即使已有合适化验也不能拟合。这是模型接入缺失，不是输入方式错误。v4 为舌下 EV 接入独立的黏膜吸收、水解与吞咽分支，未化验时有参考值，有采血时刻和已记录药物暴露时可拟合个人幅度。保留原始 EV 剂量和化验记录，不改写成游离 E2。

同时对所有当前已接入的 E2/T 路径逐一进行数值核查。统一使用酯的质量换算、正确浓度单位、同分析物叠加和独立化验，避免一部分路径沿用旧峰值锚点而另一部分路径采用新分布容积。

## 模型假设

本版输入为酯 mg，分子量换算一次；EV 舌下仅黏膜分支显式水解，吞咽分支使用口服有效参数。模型结构与参数属于经验模拟假设，独立数值求解和自动测试不能证明临床准确性。源码保留内部参数溯源，第三方版权与许可文件位于 `assets/vendor/`。

## 本版模型覆盖

| 路径 | 模型 | 当前浓度功能 |
| --- | --- | --- |
| E2、EV 口服 | 吸收→清除的二室质量模型 | 参考＋化验幅度校准 |
| E2 舌下 | 黏膜与吞咽两个二室分支 | 参考＋化验幅度校准 |
| EV 舌下 | 黏膜三室（水解）＋吞咽二室 | 参考＋化验幅度校准 |
| E2 凝胶、T 凝胶 | 皮肤输入→清除 | 参考＋化验幅度校准 |
| E2 贴片、T 贴片 | 佩戴期间恒速输入，移除后衰减 | 参考＋化验幅度校准 |
| EB、EV、EC、EEn 肌注 | 双药库→水解→清除 | 参考＋化验幅度校准 |
| TC、TE、TU 肌注 | 双药库→水解→清除 | 参考＋化验幅度校准 |
| CPA 口服 | 保留 Androcur 标签约束的一室近似 | 参考＋CPA 独立校准 |
| 其余目录项目 | 尚无本版所需独立参数 | 保留记录、提醒和实测；明确说明缺口 |

共 15 个 E2/T 参考路径和 1 个 CPA 路径。现有注射参数不能证明皮下注射与肌注等效，因此不套用于 SC、颊黏膜、喷雾、植入剂、混合酯或口服 TU。螺内酯、比卡鲁胺、GnRH 药物等不会伪装成 E2/T 浓度加减项。仍缺模型的 E2/T 记录会使对应总值显示原因，不会把未知贡献算作零。

## 输入、质量与单位

设给药量为 `D`，以产品标示的化合物 mg 输入。EV 2 mg 就输入 2，不能先手工折算 E2 再让引擎折算一遍。酯量转活性母药的质量比为：

| 化合物 | 母药 / 酯分子量 |
| --- | --- |
| EV | 272.38 / 356.50 |
| EB | 272.38 / 376.50 |
| EC | 272.38 / 396.58 |
| EEn | 272.38 / 384.56 |
| TC | 288.42 / 412.60 |
| TE | 288.42 / 400.59 |
| TU | 288.42 / 456.70 |

`A(t)` 是模型中央室内母药的 mg；模型体重 `W` 以 kg 输入：

```text
E2: C(pg/mL) = A(mg) × 10^9 / [2 L/kg × W kg × 1000 mL/L]
T:  C(ng/dL) = A(mg) × 10^8 / [1 L/kg × W kg × 1000 mL/L]
```

默认体重 70 kg 是可编辑参考假设，不是由身份或旧数据推断出的个人体重。模型体重范围 20–400 kg 是输入有效性约束，不是临床范围。E2 的 2 L/kg、T 的 1 L/kg 是该参考算法使用的表观分布容积。

凝胶输入有效激素 mg，不输入凝胶克数。E2 贴片输入标称 μg/day，转 mg/h 时除以 24000；T 贴片输入标称 mg/day，转 mg/h 时只除以 24。两者都需要实际佩戴时长。CPA 输出独立 ng/mL，不能与 E2 或 T 相加。

## EV 舌下的具体方程

中央室二室核 `B2(t;ka,ke)`、三室核 `B3(t;ka,kh,ke)` 的定义分别为以下质量守恒方程中、单位初始输入时的中央室质量：

```text
二室： dI/dt = -ka I;                    dA/dt = ka I - ke A
三室： dI/dt = -ka I; dE/dt = ka I-kh E; dA/dt = kh E - ke A
初值： I(0)=1，其他=0；t<0 时给药贡献为0。

r = 272.38/356.50
θ = 0.11（默认黏膜分流比例，可编辑为0–1）
A_EV_SL(t) = D × r × [θ × B3(t;1.8,0.07,0.41)
                   +(1-θ) × 0.03 × B2(t;0.05,0.41)]
```

速率单位均为 h⁻¹。黏膜支路有酯水解延迟；吞咽支路的 3% 有效比例与口服吸收率是模型经验假设。θ 不能仅由含服分钟数确定，也不是测得的临床个体参数。

游离 E2 舌下不经过酯水解，吞咽支路 `ka=0.32`；口服 EV 整体使用 `0.03 × B2(0.05,0.41)`。口服 EV 使用有效吸收参数，实际求值没有额外水解层。

零背景、W=70 kg、θ=0.11、单次 EV 舌下 2 mg 的可复算示例：

| 给药后 | E2 药物增量 pg/mL |
| ---: | ---: |
| 0 h | 0 |
| 1 h | 49.407159 |
| 4 h | 157.621900 |
| 8 h | 160.473811 |
| 24 h | 60.105612 |

这些是**方程的测试数字**，不是对使用者实际水平的预测保证。界面若仍使用 MTF 治疗前背景，则未校准总值会再加一次该背景。一次有效化验可以缩放合成增量，不能据此识别 θ、水解速率或内源激素变化。

## 其他参考参数

E2 非注射清除率 0.41，注射有效清除率 0.041；T 对应为 0.5 和 0.035 h⁻¹。不同路径的有效清除常数来自参照算法，不应解释为同一个人的真实母药清除率在给药方式间改变。

| 注射酯 | 首分支比例 | k1 首分支 | k1 另分支 | 水解 kh | 有效形成分数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| EB | 0.90 | 0.144 | 0.114 | 0.090 | 0.1092 |
| EV | 0.40 | 0.0216 | 0.0138 | 0.070 | 0.0623 |
| EC | 0.229164549 | 0.005035046 | 0.004510574 | 0.045 | 0.1173 |
| EEn | 0.05 | 0.0010 | 0.0050 | 0.015 | 0.12 |
| TC | 0.35 | 0.025 | 0.005 | 0.20 | 0.025 |
| TE | 0.40 | 0.035 | 0.008 | 0.20 | 0.025 |
| TU | 0.10 | 0.008 | 0.0009 | 0.20 | 0.025 |

每一支路采用 `D × 分子量比 × 形成分数 × B3`，按比例相加。有效形成分数是经验幅度参数，不是说明书中测得的绝对生物利用度。EEn 的源码 `fast`/`slow` 命名与速率大小反向，故表中改称首分支/另分支，保留原数值。

E2 凝胶 `ka=0.0193`、有效比例 0.05；T 凝胶 `ka=0.05`、有效比例 0.10。采用普通手臂/大腿参考，不模拟部位倍率或不同产品的生物等效性。贴片以标称速率恒速输入，移除后只消除。

## CPA 保留标签约束模型

CPA 使用 [Androcur SmPC 5.2](https://www.medicines.org.uk/emc/product/15996/smpc) 中两片 50 mg、合计 100 mg 的约 3 h / 285 ng/mL 观测锚点。本版保留 v3 的 43.9 h 终末半衰期、由峰时反推的吸收半衰期 0.449155675 h，以及一次幅度锚定；已经包含吸收影响，不再乘 88%。完整推导见 [MODELS-v3.md](./MODELS-v3.md)。

CPA 对应母药总浓度，不包括活性代谢物，不从其浓度推算 T 抑制；CPA 也不随 E2/T 模型体重设置缩放。

## 化验、背景与时间

三个分析物独立处理，单位按所选分析物换算：E2 的 pmol/L×0.27238=pg/mL；T 的 nmol/L×28.842=ng/dL；CPA 的 nmol/L×0.41694=ng/mL。不能仅看到 nmol/L 就推断分析物。

参考背景继续采用 [Vlot 2019 Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC6852079/) 成人治疗前中位数：MTF 情境 E2 28.5999 pg/mL、T 547.998 ng/dL；FTM 情境 E2 50.93506、T 37.4946。此背景可编辑，既不是用药后内源水平，也不是治疗目标。CPA 背景固定为 0。

`referenceBaselines` 和个人拟合的固定 `baselines` 独立。每一分析物的背景只加一次：

```text
reference(t) = 参考背景 + Σ 该分析物各途径的参考增量(t)
calibrated(t) = 个人固定背景 + α × Σ 该分析物各途径的参考增量(t)
α = Σ[x_i × (化验_i - 个人固定背景)] / Σ[x_i²]
```

`α` 必须有限且为正；采血时没有已记录暴露、单位不匹配、未来采血或化验低于所设基线等情况会保留明确原因。多途径只拟合一个共同倍率，不声称每一种制剂都分别完成了个人校准。一个采样点会强制曲线经过该点，但零拟合误差不能验证曲线形状。当前不自动拟合清除率；有限数据也不能自动证明这类参数可识别。

旧日志完整保留。重算是回顾性幅度拟合：补充过去的化验或漏记剂量可使历史估计改变，历史实测不变。新增采血之后同一路径的剂量不应改变该化验对应的拟合倍率。

桌面界面仅将截至当前已发生的给药交给模型；未来记录保留并标注“未发生，暂不计入估算”，未来虚线不自动追加给药或提醒计划。底层引擎用于独立数值检查时可按显式查询时间激活未来事件，但这些事件不能污染更早时刻的校准；未来化验不参与拟合或绘制为已取得的实测点。

未来才开始的新途径不参与当前拟合，也不会让当前已有校准消失；到该途径开始贡献的时间点，若它没有被化验覆盖，则退回参考值，不能自动继承另一途径倍率。时间明确的未来无效给药和未知药物也不会提前污染当前值，到对应时间后再显示不可计算原因。时间本身无效则无法做这种隔离。

旧版每条 E2/T 路径的单室“吸收/消除半衰期”配置保留在备份数据中，**不再作为新多室模型参数使用**，结果会说明这一点；不能用两个旧字段控制新的三室与分流方程。贴片实际佩戴时长继续生效，CPA 仍使用其一室设置。

## 数值审计与临床证据分开

二室核用 `expm1` 和相等速率的解析极限，避免两个接近指数相减。三室核在速率接近或给药极早期使用 3×3 矩阵指数；正常分离速率用解析式。TE 的首分支 `ka=ke=0.035` 是可去奇点，不能返回 0，也不能只给分母加一个任意常数。

`tests/pk-independent-v4.test.js` 的 21 项检查全部通过：用不依赖产品求解器的 RK4 质量平衡积分交叉检查 13 条非贴片 E2/T 路径、每条 7 个时点；另以恒速方程检查两个贴片单位、移除尾部，检查 EV 分流边界、酯换算一次、体重比例、混合途径单次基线、pmol/L 化验流程，以及四种未来记录隔离场景。产品还有目录、输入持久化、旧 API 与桌面流程测试。测试证明的是方程、量纲和程序连接的一致性，不构成临床准确性验证。

[Doll 2022](https://pubmed.ncbi.nlm.nih.gov/34781041/) 研究的是 17β-E2，不能把其观测峰值当成 EV 含服水解参数的来源。[Progynova 说明书](https://www.medicines.org.uk/emc/product/1417/smpc) 对应口服；它不确证本版 EV 舌下的经验分流与水解常数。本版仍是**经验软件模型**，不是经过临床验证的 EV 舌下模型。旧版强制匹配 Doll 单个峰值的参考幅度已被替换，新旧未校准数值会变化；个体化验会按新形状重新计算幅度。

仍未模拟 E2 对 T 的抑制、外源 T 芳香化、月经周期、SHBG、疾病、相互作用和制剂差异。参考值和个体幅度校准可供回顾记录与比较模型，不承担自动给药建议或真实浓度检测。
