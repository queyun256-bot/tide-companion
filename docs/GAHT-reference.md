# 浓度页面的 GAHT 监测参考

核对日期：2026-10-12。参考信息只在浓度曲线页的当前浓度卡片显示；不参与药代模型、化验校准或用量计算，也不把估算点标为“达标”“安全”或“危险”。

| 模式 / 项目 | 页面标注 | 适用条件 |
| --- | --- | --- |
| MTF / 雌二醇 | 指南监测参考 100–200 pg/mL（约 367–734 pmol/L） | 女性化 GAHT 临床采血监测参考；需结合给药途径和采血相对用药时间 |
| FTM / 总睾酮 | 指南监测参考 400–700 ng/dL | 明确限于庚酸或环戊丙酸睾酮注射间隔中点采血，不覆盖所有制剂或整条曲线 |
| FTM / 雌二醇 | 未设统一 E2 目标 | 下列指南的男性化监测表未列统一 E2 目标，不套用女性化治疗范围 |
| CPA | 不标目标范围 | CPA 是药物浓度，不冒用激素监测目标 |

来源：Hembree 等的 [Endocrine Society 2017 指南](https://academic.oup.com/jcem/article/102/11/3869/4157558)，DOI 10.1210/jc.2017-01658，表 14（男性化）和表 15（女性化）；Coleman 等的 [WPATH SOC8](https://pmc.ncbi.nlm.nih.gov/articles/PMC9553112/)，DOI 10.1080/26895269.2022.2100644，附录 C 表 5。

十一酸睾酮长效针剂的监测时点是下次注射前；经皮睾酮需每日使用至少一周，距涂药至少两小时采血。这些条件在睾酮卡片详情中保留，避免用户把针剂中点范围用于其他制剂。Endocrine Society 表 14 的印刷重复文字曾有 [2018 更正](https://academic.oup.com/jcem/article/103/2/699/4675081)，本项目采用更正后 400–700 ng/dL。

E2 数值是指南监测参考，并非已证实的个体最佳范围或瞬时安全界线。[Winston-McPherson 等的 2025 系统综述](https://pubmed.ncbi.nlm.nih.gov/40552461/)，DOI 10.1089/lgbt.2024.0407，纳入 49 项研究，未找到证据证明 100–200 pg/mL 可保证最佳女性化效果或减少不良事件。因此页面同时呈现范围与证据局限，不据此自动推荐剂量。

实现：`src/gaht-reference.js` 保存内容，`src/chart.js` 的 `hormoneCards` 通过 `{ referenceMode: 'mtf' | 'ftm' }` 显式启用；未传此选项的概览及化验页不增加参考卡。新样式文件为 `src/gaht-reference.css`。
